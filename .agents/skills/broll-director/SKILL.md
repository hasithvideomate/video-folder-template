# B-roll director

For phone-photo treatment load ../iphone-photo-look/SKILL.md when relevant; inspect actual stills using ../image-review-validation/SKILL.md.

Read ../production-director/SKILL.md. First inspect supplied images/videos in Assets/; do not require paid generation when existing media fits.

Map each shot to the approved script line or purpose. Separate identity, product, style and location references. Specify a plausible camera, motivated light and concrete action. For interactions describe grip/contact, weight, lift, orientation, fabric follow-through and settling. Preserve product/brand integrity and required details.

Use scene-reference acceptance and a representative sample before an approved remaining generated-shot scope. Verify current model-specific inputs; never mix incompatible reference/first-frame modes or silently change the model after approval.

Talking-head restrictions are not universal B-roll rules. Permit brief-appropriate movement. Preserve the original narration when inserting cutaways and mute incidental B-roll audio by default; keep intentional sound only when requested. Do not add speech, music or new product claims.

Review actual footage for identity drift, fingers/contact, product geometry, feet, fabric, background and light continuity. Missing temporal coverage is uncertain. Keep replacement takes separately versioned and preserve operation/cost records.

For timeline placement load ../premiere-edit/SKILL.md, follow File/agents.md and the actual supplied safe-zone guide. Keep caption placement separate from B-roll guide rules.
