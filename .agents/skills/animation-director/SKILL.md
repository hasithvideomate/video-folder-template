# Animation director

For detailed packages load ../animation-script-planning/SKILL.md; for animated-feature craft load ../pixar-animation-director/SKILL.md and its relevant references. Track local stages/dependencies with ../animation-production-desk/SKILL.md.

Read ../production-director/SKILL.md for local project operation, optional direct generation and approvals. Follow File/docs/ANIMATION_FARM.md for animation-specific roles, automatic per-download review, protected pacing and actual helper limits. Use File/scripts/animation_review.py for general animation shot packets/gates; do not force silent shots through UGC validators.

Preserve the original narrative, dialogue, chronology and ending. Record story beats without inventing replacements. Establish character proportions, materials, stylization, location geography, scale and lighting. Track screen direction, eye lines, entries/exits, prop ownership and contact between shots.

Save a source-to-shot plan under File/ with actual reference paths and clearly versioned proposed assets. Plan reference views appropriate to the story. Reuse user-selected references/direction. Independently review the first three storyboard frames (or all if fewer exist) before continuing dependent work; do not request routine human acceptance again for already selected direction. These are local workflow gates that the agent must track; there is no remote server enforcing them.

Use clean individual accepted storyboard frames for video, not labeled contact sheets. Verify that the chosen model/endpoint supports the reference input before requesting generation. A sample video is reviewed before an approved remaining-clip run.

Current root rules apply to animation too: generated 720p, locked camera/framing, stationary scenery, no zoom/reframing or added text. Animate intended subjects and preserve source action. Use one uninterrupted generated shot per job and place cuts in Premiere. Use permitted story-motivated SFX/ambience; keep no-background-music default unless the user changes it.

Inspect character, prop, geography and light continuity with actual available evidence. Motion, pacing and transitions need independent temporal review; stills cannot prove them. Preserve prior takes and regenerate only the requested task after preview/authorization. Protect anticipation, reaction, intentional holds and complete action/ending; UGC silence thresholds are not animation cut rules.

Use ../premiere-edit/SKILL.md to assemble accepted local media and review the actual sequence. Update File/memory.md with selected boards/takes and unresolved continuity issues.

Instruction version: animation-director@1.1.0.


For confirmed fixable review defects, follow File/docs/AUTO_REPAIR.md automatically: preserve the same characters/scenes, repair the affected property, independently re-review, and resume dependent work. A findings-only message is not completion when authorized repair remains possible.
