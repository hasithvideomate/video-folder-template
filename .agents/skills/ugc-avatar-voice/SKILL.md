# UGC Avatar Voice Design

Read ../ugc-director/SKILL.md, ../ugc-video-pipeline/SKILL.md and ../kie-generation-runner/SKILL.md. Voice design is local planning. No Omni registration adapter or automatic verifier is bundled; never fabricate IDs or use Market createTask as registration.

## Design inputs
Use the exact script, requested language/accent, delivery, portrayed role and selected reference. Appearance can inspire a fictional persona proposal; it does not establish a real person's age, ethnicity, profession or natural voice. Do not infer accent from appearance or default non-English scripts to American English.

Design an original persona, not a real-person/celebrity imitation. A supplied face does not request voice cloning. Match supported script intent: clear explanation, reassurance, candid confession or restrained promotion.

Save a UGC01_VOICE block in File/production.md with:
- User-requested language/accent and original persona/register.
- Explicitly selected timbre/pitch, conversational pace, pauses and source-word emphasis.
- Clean close speech, without music/effects/ambience or announcer polish.
- A short verbatim example from the source in its actual language.

If a verified endpoint uses audio_id/preset, name, voice_description and example_dialogue, map the proposal into its actual schema. Historical preset names, duration lists and free-pricing claims remain unverified until checked.

## Binding when separately supported
1. Obtain human acceptance of the actual avatar.
2. Prepare concrete voice/character previews with actual references and current contract/cost.
3. Obtain authorization for those external requests; planning alone is insufficient.
4. Save returned IDs, avatar/voice-design versions and receipts.
5. Reconcile ambiguous outcomes before another registration.
6. Verify allowed video reference/audio/character/first-frame combinations; do not assume they can be mixed.
7. Review an actual-script sample before the remaining clips.

Changed voice/avatar selections can invalidate bindings and sample acceptance. Reuse an existing actual binding only when its source versions still match; text similarity does not prove provider reuse.

## Timing and review
Preserve every word and ordered source span. Estimate using actual language/delivery and measured samples, allowing breath/reaction time within supported durations. Do not apply a universal 2.5-words-per-second rule, omit words or force unnatural speed.

Talking performances articulate naturally with restrained script-matched gestures. Neutral closed lips apply to references. Keep complete hands in frame, fixed camera and speech-only default. Review actual sound, wording, voice consistency, motion and lip sync; absent evidence remains uncertain.

No automatic transcription, registration or paid repair loop is installed. Use the existing Premiere workflow for final editing.
